Help

        
    

    

        
This page is a live log of HTTP traffic handled by the mock server.

        

            

                
Pause / Resume

                
Freezes the table while buffering up to 200 new requests. Resume displays buffered traffic. Older omitted requests are counted.

            

            

                
Export HAR

                
Downloads the current request log as a HAR (HTTP Archive) file, a JSON format for captured HTTP traffic. Only requests already in the log are included.

            

            

                
Dark / Light

                
Switches the page between dark and light themes. The choice is remembered in this browser.

            

            

                
Filter

                
Shows only log entries whose method, path, or status match what you type.

            

            

                
Keyboard

                
Arrow keys move through the traffic log and load Request/Response details. Home and End jump to the first or last visible row. / focuses the filter.

            

            

                
Clear log / Reset responses

                
Clear log removes traffic across connected tabs without changing response sequences. Reset responses restarts sequences without deleting traffic.

            

            

                
Refresh

                
Reloads the configured routes list. Routes also refresh automatically every few seconds after request files change.

            

            

                
Hide / Show routes

                
Collapses the routes list to give the request log more vertical space. The choice is remembered in this browser.

            

            
Resize panels
Drag a divider to resize adjacent panels. Focus a divider and use arrow keys (Shift for larger steps), Home or End. Double-click restores its default size. Sizes are remembered.

            
Inspect & copy
Pretty formats valid JSON; Raw preserves captured content. Copy body copies the captured text (or base64 for binary data). Copy cURL creates a shell-quoted command for complete text requests. Captured credentials are included.

            
Route diagnostics
Select a route to inspect its requirements and response template. Request details identify the selected fixture and sequence position. Unmatched requests list nearby routes and failed constraints.

            
Reload status
The banner shows the active configuration revision and last successful load. Failed reloads retain active routes and show the error. On narrow screens, use Back to traffic & routes to return from the inspector.
