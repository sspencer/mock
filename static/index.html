Help

This page is a live log of HTTP traffic handled by the mock server.

Pause / Resume
Stops adding new requests to the log. The mock server keeps serving traffic. Requests that arrive while paused are not recorded. Resume starts showing new requests again.
Export HAR
Downloads the current request log as a HAR (HTTP Archive) file, a JSON format for captured HTTP traffic. Only requests already in the log are included.
Dark / Light
Switches the page between dark and light themes. The choice is remembered in this browser.
Filter
Shows only log entries whose method, path, or status match what you type.
Clear
Removes all logged requests from the page and the server. This also resets rotation counters used by repeating mock responses.
Refresh
Reloads the configured routes list. Routes also refresh automatically every few seconds after request files change.
Hide / Show routes
Collapses the route registry to give the request log more vertical space. The choice is remembered in this browser.

Press Escape, click outside, or use Close to dismiss.
