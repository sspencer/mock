Help

        
    

    

        
This page is a live log of HTTP traffic handled by the mock server.

        

            

                
Pause / Resume

                
Freezes the table while buffering up to 1,000 new requests. Resume displays buffered traffic. Older omitted requests are counted.

            

            

                
Export HAR

                
Downloads the current request log as a HAR (HTTP Archive) file, a JSON format for captured HTTP traffic. Only requests already in the log are included.

            

            

                
Dark / Light

                
Switches the page between dark and light themes. The choice is remembered in this browser.

            

            

                
Filter

                
Shows only requests that match every term you type. 2xx to 5xx match a status class, matched and unmatched whether a route answered, a method name such as post that method, and route:Name (or route:"Two words") the requests a route answered. Other terms search the method, URL, status and labels. Put - before a term to exclude it, as in -2xx. Clicking a route's hit count filters to its requests; click again to clear.

            

            

                
Keyboard

                
Arrow keys move through the traffic log and load Request/Response details. Home and End jump to the first or last visible row. / focuses the filter.

            

            

                
Clear log

                
Clear log removes traffic across connected tabs.

            

            

                
Refresh

                
Reloads the configured routes list. Routes also refresh automatically every few seconds after request files change.

            

            

                
Hide / Show routes

                
Collapses the routes list to give the request log more vertical space. The choice is remembered in this browser.

            

            
Resize panels
Drag a divider to resize adjacent panels. Focus a divider and use arrow keys (Shift for larger steps), Home or End. Double-click restores its default size. Sizes are remembered.

            
Inspect & copy
Pretty formats valid JSON; Raw preserves captured content. Copy body copies the captured text (or base64 for binary data). Copy cURL creates a shell-quoted command for complete text requests. Captured credentials are included unless mock runs with -R (--redact), which masks them before they are logged.

            
Route diagnostics
The number beside each route is how many requests it has answered. Select a route to inspect its requirements and response template, plus a sample cURL command for the mock server. Copy cURL copies it; path parameters such as :id are filled with sample values. Request details identify the route that answered (the first one that matched). Unmatched requests list nearby routes and failed constraints. Copy as route copies a draft .http section that answers the request, to paste into a request file; for a request a route answered, the draft reuses its response and is a starting point for a more specific variant, which must go above that route to match first. Resend opens an editor with the request's method, path, headers and body; Send replays it through the admin server, as if a client had sent it to the mock port, and selects the new request, labeled resent. Compare… picks a request; select another and choose Compare with #N to see both side by side: method, path, status, the route that answered, query parameters, headers, and a line diff of the bodies (JSON is compared with sorted keys). Only differences hides what is the same; Swap exchanges the sides. Copy unmatched as routes, above the traffic list, copies one draft section per distinct method and path among all unmatched requests in the log (proxied ones use the upstream response).

            
Reload status
Failed reloads retain active routes and show an error banner only when needed. On narrow screens, use Back to traffic & routes to return from the inspector.
